# Phase 0 Decisions

### Decided
- **Site structure:** Single page. The nav bar links jump to sections on the same page (`#experience`, `#projects`, etc.). Project detail pages may be added later as separate routes without restructuring.
- **Featured experiences:** The two co-ops, Babel Street and Verisk, get the most prominent treatment (larger cards, all highlights shown, placed first). Scout and Ventus Health appear in a lighter, more compact style. *Superseded (2026-10-16): see "Experience" and "`featured` removed" (Phase 2).*
- **Experience links:** Experiences can carry links, just like projects. Scout will link to the GitHub repos for its client work (NUMAC and 3 Stones), shown as small repo links on the Scout entry.
- **Projects:** All three (CodeStack, Fakebook Crawler, Hexagonal Reversi) are displayed equally, with no single featured project. Each links to its GitHub repo; no live demos.
- **Domain:** None yet. The site runs on the free Vercel URL until launch, when a domain is purchased and connected (Phase 7).

- **Tagline:** "Software engineer who learns fast, adapts quickly, and loves a challenging problem." (owner edited "hard" to "challenging" in Phase 2) Stored in `resume.json` as `basics.tagline` and shown in the hero section.
- **About section:** A short personal blurb directly below the hero, covering background, co-op work, and interests outside code. Stored in `resume.json` as `basics.summary`.

- **Hero load animation: Blur-in words (owner choice, approved 2026-10-16):** The owner tried all the options in the demo and chose Blur-in words over Design's gentle fade-up. This supersedes the "nothing in the hero animates on load" rule (spec §7 rule 5). Each word of the greeting and of the tagline is an inline-block span that animates from `opacity: 0; filter: blur(10px); transform: translateY(4px)` to its resting state over 700ms with `cubic-bezier(0.22, 1, 0.36, 1)`, staggered 45ms per word, with the count running on from the greeting into the tagline. The hero link row fades in (opacity only, 500ms ease) at 700ms. The photo does not animate (it is the LCP element). It plays once on load, is CSS only with `animation-fill-mode: backwards` (the resting CSS is the final state), causes no CLS, and is declared only under `prefers-reduced-motion: no-preference`. The words are split at build time from `resume.json`; the spans are `aria-hidden` and a visually hidden copy keeps each string as one accessible text. Tradeoffs accepted: `filter` animation costs more than opacity and transform, and the per-word spans add markup.
- **Hero link hover: Soft circle (owner choice, approved 2026-10-16):** Chosen in the Variant Lab demo. This supersedes the "Hero links" entry's "No box around the icons" (for hover only; at rest there is still no box) and its -6° tilt, which is dropped entirely. On hover, the 44px round link (`border-radius: 50%`) gets the background `color-mix(in srgb, var(--color-accent) 10%, transparent)` and the icon turns Accent: color 160ms `cubic-bezier(0.2, 0, 0, 1)`, background 160ms ease. Pressed is Accent deep. Hover rules sit under `@media (hover: hover)`; keyboard `:focus-visible` gets the focus ring only. No movement, so reduced motion keeps everything. Accent icon on the circle is 4.3:1 (passes 3:1 non-text). Spec §6.1.
- **Technology item hover: Lift (owner choice, approved 2026-10-16):** Chosen in the Variant Lab demo. Supersedes "Interaction: none" (spec §6.3). Under `@media (hover: hover)`, the item's contents rise `translateY(-4px)` (180ms `cubic-bezier(0.2, 0, 0, 1)`) and the name turns Accent (180ms ease); the logo stays Charcoal. It stays a non-focusable list item. Reduced motion: name color only. Accent on Paper is 4.9:1 for the 15px/600 name. Tradeoff accepted: hover on a non-interactive item can suggest it does something.
- **Project card hover: Hover lift (owner choice, approved 2026-10-16):** Chosen in the Variant Lab demo. Supersedes "No hover state on the card" (spec §6.5) and "no shadows" (spec §1.5). Under `@media (hover: hover)`, the border goes from Rule to Pebble, and the card moves `translateY(-3px)` and gets `box-shadow: 0 8px 24px -12px color-mix(in srgb, var(--color-charcoal) 35%, transparent)`, over 180ms. The card stays non-clickable; only its GitHub link is. Default cursor, no stretched link, and no lift on `:focus-within`, so it doesn't read as a link. Reduced motion: border and shadow only. Tradeoff accepted: a hover cue on a non-clickable card can still suggest it is clickable.
- **Experience timeline: Animated height (owner choice, approved 2026-10-16):** Chosen in the Variant Lab demo. Supersedes "Expanding the content is not animated" (spec §6.4). Native `<details name="experience">` is kept. CSS only, under `prefers-reduced-motion: no-preference`: `:root { interpolate-size: allow-keywords }`, `details::details-content { block-size: 0; overflow: clip; transition: block-size 320ms cubic-bezier(0.2,0,0,1), content-visibility 320ms allow-discrete }`, `details[open]::details-content { block-size: auto }`. Browsers without support snap (acceptable). The scroll correction and the rail update run 320ms plus one frame after `toggle` when the animation applies, and on the next frame otherwise. No new dependencies.
- **Color modes: light and dark with a toggle (owner choice, approved 2026-10-16):** Supersedes "Color modes: One palette, light only" above and puts dark mode back in scope. No System option (owner: "system seems unnecessary"); one button toggles light and dark. Dark palette, same token names: Paper `#1A1816`, White (card surface) `#24211E`, Charcoal `#EDEAE6`, Pebble `#A8A09A`, Accent `#E56B60`, Accent deep `#F2958C`, Rule `#3A3531`; the card hover shadow uses black at 75% instead of Charcoal at 35% (`0 8px 24px -12px color-mix(in srgb, #000 75%, transparent)`; light is unchanged). All text pairs pass AA (lowest: Accent on cards, 5.0:1). Toggle: a 44px round `<button>` with `aria-pressed` (pressed = dark) and a visually hidden label "Dark mode"; Tabler outline `moon` in light, `sun` in dark, 22px; hover is the hero links' soft circle with an Accent icon, pressed Accent deep, standard focus ring. Placement: at 1200px and up, in the rail at the right of "Ryan Chen"; below 1200px, absolutely positioned in the top-right corner of the browser window (scrolls away; glyph 16px or the safe-area inset from the top and right edges), with main's top padding raised to 60px so it clears the hero. Theme stored as `data-theme` on `<html>` and in `localStorage` key `theme`; a blocking inline `<head>` script reads only the stored key and sets it before paint. First visit always starts light (owner choice); the system color setting is not followed, and dark applies only after a click, which is remembered. Switching fades colors over 240ms, only during the switch, instant under reduced motion. Spec §1.1, §1.3, §1.5, §2, §6.9.
- **`featured` removed (approved with the spec at the Phase 2 checkpoint, 2026-10-16):** Every experience uses one card style, with no featured or compact variant, ordered by date (see "Experience"). The `featured` flag is removed from `data/schema.ts` and `resume.json` (Backend; removed in Phase 3, 2026-10-16). Spec §6.4 and §11 #6. This supersedes the Phase 0 "Featured experiences" entry, the Phase 1 "`featured`" entry and "Compact experiences" above.
